# Página personal de Diego Castillo Rivera

Página para la práctica de Criptografía de ESCOM-IPN, hecha con HTML, CSS y JavaScript.

Incluye presentación con fotografía, formación académica, proyectos, hobbies con tres imágenes, contacto, GitHub, CV en PDF y una sección de RSA con un ejemplo interactivo.

## Abrir la página

Abre index.html en un navegador. La estructura ya está preparada para GitHub Pages, con index.html en la raíz y rutas relativas para imágenes, estilos y documentos.

## Publicar en GitHub Pages

1. Crea un repositorio en tu cuenta y sube todo el contenido de esta carpeta conservando las carpetas assets y documentos.
2. En Settings > Pages selecciona Deploy from a branch, la rama main y la carpeta / (root).
3. Guarda y espera a que GitHub confirme la publicación. El enlace de la página aparecerá en esa misma sección.

La disponibilidad de GitHub Pages depende de la visibilidad del repositorio y del plan de la cuenta. Una página de Pages pública puede ser vista por cualquier persona con su dirección.

## Actualizar

- Fotografías y descripciones: site-data.js.
- CV: documentos/CV_Diego_Castillo_Rivera.pdf.
- Llave pública: agrega su archivo en documentos y actualiza publicKey en site-data.js cuando esté lista. La llave privada permanece fuera del repositorio.
- Estilos y colores: styles.css.
